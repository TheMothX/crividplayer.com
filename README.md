# crividplayer.com

Landing page for Crivid IPTV Player. Static HTML, no build step.

- `index.html` — the whole page: inline CSS, one small inline script for the screenshot slider.
- `img/` — screenshots captured from the app on Android TV (NVIDIA Shield), plus the app icon.

Deployed by Cloudflare Pages on push to `main`.

## Screenshots

Shots must come from the **showcase playlist** (`~/crivid_fake_provider/make_showcase.py`),
never the country-tagged one. Country folders and pipe-separated channel names read as
pirate IPTV to store reviewers — that pattern is what got the Amazon build rejected four
times. Never publish shots containing real film artwork either.
